From the workshop 7 and the provided code, 
several important concepts in C++ programming have been highlighted and practiced:
Inheritance: 
Creating a derived class (SavingsAccount) from a base class (BankAccount) demonstrates the principle of inheritance. 
This allows SavingsAccount to inherit member variables and functions from BankAccount, 
promoting code reuse and organizational clarity. 
The constructor of SavingsAccount initializes both its own members and those 
inherited from BankAccount using an initializer list, 
showcasing how derived classes can extend the functionality of base classes.

Shadowing Member Functions: 
The write and read functions in SavingsAccount override the virtual functions declared in BankAccount. 
This demonstrates how derived classes can provide their specific implementations of
 functions defined in the base class, allowing for polymorphic behavior. 
The use of virtual in the base class and override in the derived class makes the intention 
clear and helps the compiler catch errors.

Accessing Shadowed Member Functions: Through the process of overriding, 
SavingsAccount can still access the write and read functions of its base class (BankAccount) by calling them directly 
(e.g., BankAccount::write(out) within SavingsAccount::write). 
This shows how to access shadowed or overridden member functions, 
which is useful when the derived class wants to extend rather than completely replace the functionality of the base class.

The same thing can be applied to Ms2:
