Another thing that was difficult for me to do was deep copying.
Deep copying is essential in C++ when an object owns resources that are allocated dynamically, such as memory allocated on the heap. 
A deep copy involves creating a copy of the allocated resource itself, not just copying the address (pointer) to the resource. 
This ensures that the original and the copy can operate independently, modifying or deleting their resources without affecting 
each other.
This operator is used to copy the state of one Icecream object (other) 
into another Icecream object (the one this method is called on). 
The method operator= is defined to take a constant reference to another Icecream object named other and return a reference to an Icecream object. 
The return type Icecream& allows for chaining assignment operations:
Icecream& Icecream::operator=(const Icecream& other)
and if (this != &other), checks if the object being assigned to (*this) is not the same as the object being copied from (other).
 This is important because without this check, self-assignment would lead to deleting 
the object's own resources (such as dynamically allocated memory), which could result in data loss or memory corruption.
